# 학교 양식 확인 개발판

학교 전용판의 두 갈래 홈(시험지 수합 / 시험지 편집), 문항 목록, 난이도 지정 및 순서 편집 UI를 공유판에 유지합니다. 수합 시에는 사용자가 학교 양식을 직접 선택합니다.

## 사용 순서

1. `HWPExamAssembler.exe`를 실행하고 **시험지 수합**을 선택합니다.
2. 학교 양식 HWP/HWPX와 새로운 수합본 경로를 선택하고 작업 사본을 엽니다.
3. **학교 양식 인식 결과**에서 예시 서식, 명시된 지시, 판정 및 근거 위치를 확인합니다.
4. 추가 지시가 있다면 `본문 바탕 10pt, 줄간격 160%`처럼 대상과 단위를 적습니다. 양식 지시보다 우선할 기준이라면 **추가 지시를 이 작업의 기준으로 지정**을 선택합니다. 원래 근거는 보관됩니다.
5. 확인 결과를 저장한 뒤 예시 문항과 마지막 고정 블록을 기존 방식으로 정리하고 출제 파일을 수합합니다.
6. 완성된 문서를 다시 열어 명시된 규칙과 서식 속성을 대조합니다. 불일치와 미확인 항목은 완료 안내에 표시됩니다.

## 개인 AI로 분석한 JSON 가져오기

**실제 문항·정답이 없는 빈 양식의 서식 분석은 시험 문제 제공과 다릅니다.** 번호·폰트·간격·상자 구조를 분석하는 데 실제 출제 파일은 필요하지 않습니다. 프로그램이 AI에 파일을 자동 전송하지 않으며, 개인 AI 사용은 선택 사항입니다. 예시 문항이 들어 있는 양식은 빈 양식과 구분해 주세요.

1. **학교 양식 인식 결과** 화면에서 **AI용 서식 근거 저장…**을 누릅니다. 프로그램이 읽은 속성·발견된 지시문·선택한 양식의 SHA-256을 저장합니다.
2. **AI 분석 프롬프트 복사**를 누릅니다. 개인적으로 사용하는 AI에 프롬프트와 학교 양식, 작성 지침, 방금 저장한 서식 근거를 함께 제공합니다. AI가 HWP를 읽지 못하면 화면을 확인할 수 있는 PDF/이미지도 제공합니다.
3. AI가 반환한 JSON 객체 하나를 UTF-8 `.json` 파일로 저장합니다. 코드블록의 백틱이나 설명문은 제외합니다.
4. **AI JSON 불러오기…**로 파일을 엽니다. **JSON 전체 근거**에서 명시 규칙·관찰·추정·확인 불가, 조건, 미지원 속성을 모두 확인합니다.
5. 비교 가능한 후보가 맞는지 대조한 뒤 **JSON의 비교 가능한 후보를 이번 작업의 기준으로 사용**을 선택합니다. 불러오기만으로는 기준으로 채택되지 않습니다. 필요한 경우 추가 지시로 충돌을 수정하고 확인 결과를 저장합니다.

배포물의 `AI양식분석` 폴더에는 상세 프롬프트, JSON Schema, 빈 입력 양식, 가상 예제가 있습니다. **가상 예제의 10pt/11pt 등은 실제 학교의 규칙이 아닙니다.** 빈 양식은 43개 필수 점검을 모두 unknown으로 포함합니다.

프롬프트는 문제 번호, 한글/영문 글꼴, 크기, 줄간격, 보기·선택지 구성, 보기 상자·그림의 위치와 여백, 용지·단 구성, 줄글 지시문을 분석하도록 지시합니다. 필수 항목을 확인하지 못해도 삭제하거나 임의의 기본값으로 채우지 않고 unknown으로 남깁니다. 지원 property로 표현할 수 없는 규칙은 notes에 기록합니다.

### JSON을 해석하는 기준

- explicit: 작성 지침에 명시된 규칙. 원문 인용과 근거 ID가 필수입니다.
- observed: 문서에서 관찰한 값. 학교의 의무 규칙과 구분합니다.
- inferred: 추정. 자동 비교에서 제외하고 수동 확인 대상으로 남깁니다.
- unknown: 확인 불가. 값과 단위는 null입니다.

`high` 신뢰도, 역할 전체(`all`), 조건 없음이며 명시 지침 또는 원본 속성 근거가 있는 관찰값만 비교 후보가 될 수 있습니다. 사용자가 선택한 후보도 다른 기준과 충돌하면 충돌로 표시합니다. JSON의 신뢰도·근거 표기가 실제 사실인지는 사람이 원본과 대조해야 합니다.

현재 JSON 자동 비교는 기존 역할의 글꼴, 크기, 줄간격, 굵게/기울임, 자간/장평, 문단 정렬, 번호·기호, 문단 단위 배열, 상자/그림 크기, 글자처럼 취급과 본문 배치에 연결됩니다. **페이지 설정, 개별 위치 좌표·배치 기준·여백·테두리, 화면 한 줄/여러 줄 배열 등은 JSON에 보관하고 전체 근거에 표시하지만 자동 비교하지 않습니다.** 기존 원본 추출이 해당 항목을 읽지 못하면 “지시문만 확인”으로 남습니다.

잘못된 타입·단위·범위, 중복 키/ID, 존재하지 않는 근거 ID, 지원하지 않는 필드는 가져오기 단계에서 거부합니다. 일부 필수 점검이 누락되면 누락 목록을 표시합니다. SHA-256이 있으면 선택한 양식과 대조하고 불일치 시 기준 채택을 막습니다. 해시가 없으면 동일성 미확인으로 안내합니다. JSON 안의 경로나 URL을 실행하거나 열지 않습니다.

프로그램은 외부 AI에 접속하지 않습니다. AI 선택과 자료 전달은 사용자가 직접 합니다. JSON 가져오기는 비교 기준을 추가하는 기능이며, 문서 서식을 자동 변경하는 기능은 아닙니다.

## 인식 범위

- 번호 형식과 번호 글꼴·크기, 역할 후보별 한글/영문 글꼴, 크기, 굵기, 기울임, 장평, 자간
- 줄간격의 값·유형, 문단 정렬과 앞뒤 간격 및 들여쓰기
- 선택지 기호와 한 문단/여러 문단 구성, 보기 표지
- 보기 상자·그림·기타 표 후보의 크기, 배치 기준, 정렬, 이동량, 글자처럼 취급 여부, 본문 배치, 여백 및 표 테두리
- 대상이 명시된 한국어 지시문: 글꼴, pt/포인트 글자 크기, %/pt 줄간격, mm/cm 너비·높이, 글자처럼 취급

예시와 지시문이 다른 경우, 지시문끼리 다른 경우, 여러 서식이 섞인 경우를 각각 표시합니다. 인식되지 않은 값은 기본값으로 대체하지 않습니다. 예시를 지워도 최초 서식 근거는 남습니다.

## 한계

이 버전은 **인식·대조 기능을 추가한 개발판**입니다. 추출한 규칙을 모든 문항에 자동 적용하는 기능은 포함하지 않습니다. 기존 번호 정리·네이티브 복사 기능은 유지됩니다.

발문·지문·보기 분류는 표지에 근거한 후보입니다. 표지가 없는 지문, 복잡한 중첩 도형과 묶음, 다단 안의 실제 위치는 사람이 확인해야 합니다. 한 문단에 선택지가 들어 있다고 한 줄에 모두 보인다고 판정하지 않습니다.

자유로운 한국어 전체를 이해하는 AI는 사용하지 않습니다. 조건·예외·부정·범위 표현과 지원하지 않는 추가 조건은 미해석 항목으로 남깁니다. 예: `10pt 이하`, `그림이 있을 경우`, `한 줄에 5개`.

페이지를 렌더링하여 겹침·잘림·줄바꿈을 검사하는 시각 검증은 아직 없습니다. 문서 안에 저장된 속성의 일치와 실제 인쇄 결과의 일치는 별개입니다. 그림별 서로 다른 크기를 하나의 학교 규칙으로 자동 확정하지 않습니다.

수식·그림을 텍스트나 이미지로 재작성하지 않으며 외부 AI/API로 문서를 보내지 않습니다. 분석 근거는 로컬에 보관됩니다.

## 저장되는 결과

- `수합본.hwp.format-review.json`: 최초 예시 서식, 지시문, 사용자 지정 기준, 미해석 항목, 가져온 전체 AI JSON과 근거·채택 여부 및 확인 여부
- `수합본.hwp.format-check.json`: 저장 후 다시 읽은 문서와 명시 규칙의 대조 결과

근거의 문단 번호는 XML 순회에서 부여한 **분석 문단 번호**이며 한글 화면의 페이지·줄 번호가 아닙니다. 이후 한글에서 수정하거나 앱에서 순서를 바꾸면 위 대조 결과는 이전 수합 시점의 기록입니다. 자동으로 갱신되지는 않습니다.

## 검증

- 비한글 자동 검증: 20개 테스트 파일 통과, 기존 실문서 전용 시험 1개 제외
- JSON 검증: 잘못된 입력 거부, 조건·추정 제외, 해시 불일치 차단, 후보 채택·충돌·사용자 수정, 근거 내보내기와 기록 보존
- 실제 한글: 합성 2문항 수합, 원본 해시 보존, 예시 삭제 후 분석 근거 보존, 저장 후 기존 3개 규칙과 AI JSON 선택지 크기 1개 규칙 대조
- HWPX 저장·재개방 후 서식 추출 확인
- 실제 학교 양식은 읽기 전용으로 글꼴/간격/표·그림 속성 추출 확인. 원문을 배포물에 포함하지 않음

테스트 중 발견한 첫 문단의 직접 입력 번호 선택 오류도 수정했습니다. 문서 시작의 구역 제어정보를 건너뛴 실제 캐럿 위치를 기준으로 번호만 선택합니다.

## 개발

주요 구현은 `app/services/format_analysis.py`, `app/services/ai_template_profile.py`, `app/ui/format_review.py`에 있습니다. 기존 `LiveImportSession`의 양식 준비와 저장 후 재개방 과정에 연결했습니다. `python scripts/generate_ai_template_assets.py`로 가져오기 규약에 맞춰 프롬프트·스키마·빈 양식·가상 예제를 다시 생성할 수 있습니다.

Windows, 한컴 한글, Python 3.12 환경에서 `pip install -r requirements.txt` 후 `python tests/run_no_hwp.py`로 자동 검증하고 `python -m app.main`으로 실행할 수 있습니다.

공개 배포는 GitHub의 `v0.2.0-alpha` 릴리스에서 제공합니다. 이 안내는 해당 알파 버전 기준입니다.
