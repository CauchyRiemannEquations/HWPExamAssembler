# 개인 AI로 학교 시험지 양식 분석하기

## 빈 양식 분석과 시험 문제 제공은 다릅니다

**실제 문항·정답이 없는 빈 학교 양식을 GPT 등으로 분석하는 것은 시험 문제를 제공하는 일이 아닙니다.** 번호 모양, 글꼴, 줄간격, 여백, 보기 상자와 그림 자리 같은 서식 정보를 분석하는 데 실제 출제 파일이나 완성 시험지는 필요하지 않습니다.

프로그램은 AI에 문서를 자동 전송하지 않습니다. 개인 AI 사용은 선택 사항이며, 사용자가 빈 양식과 서식 지침을 직접 제공하고 분석 결과 JSON만 프로그램으로 가져옵니다. AI용 서식 근거도 그 빈 양식에서 내보내면 됩니다.

다만 예시 문항·정답이나 비공개 내용이 들어 있는 파일은 빈 양식과 구분해야 합니다. 파일 이름이 “양식”이라는 이유만으로 내용까지 비어 있는 것은 아닙니다. 이 안내는 외부 AI 서비스의 자료 보관·처리 방식에 대한 무조건적인 보장을 뜻하지 않습니다.

## 준비할 파일

- 학교 기본 양식 HWP/HWPX와 학교에서 배부한 작성 지침
- AI가 HWP를 직접 읽지 못하면 양식을 PDF로 저장하거나 확인할 페이지의 이미지
- 프로그램의 **학교 양식 인식 결과 → AI용 서식 근거 저장…**으로 만든 JSON
- 함께 제공한 `학교양식_AI분석_프롬프트.txt`. AI가 파일을 받을 수 있으면 `template-analysis.schema.json`도 제공

학교 양식과 서식 근거를 분석 자료로 올리고 상세 프롬프트 전문을 메시지로 붙여 넣으세요. “이 자료가 분석 대상입니다”라고 지정하면 됩니다. 프로그램 내부의 **AI 분석 프롬프트 복사** 버튼도 같은 전문을 복사합니다.

## AI에 요구하는 결과

문제 번호, 글꼴과 글자 크기, 줄간격, 보기·선택지 구조, 상자·그림의 크기와 위치, 용지·단·여백을 역할별로 분석합니다. 별도로 적힌 줄글 지침도 읽고, 실제 예시와 다르면 양쪽 근거를 남깁니다.

각 규칙에는 값·단위·적용 범위·조건·근거·확실성 구분이 들어갑니다. 기본 점검 43개는 모르는 항목도 `unknown`으로 남깁니다. 예를 들어 지침의 “본문 10포인트”는 명시 규칙, 속성에서 읽힌 11pt는 관찰값, 이미지로만 추측한 크기는 추정 또는 확인 불가입니다. “그림이 있는 문항만” 같은 예외도 보존합니다.

AI가 내놓은 JSON 객체 하나를 UTF-8 `.json`으로 저장하세요. 코드블록의 백틱이나 앞뒤 설명문은 넣지 마세요. 함께 제공한 빈 양식과 가상 예제는 파일 구조를 참고하는 용도이며, 가상 예제의 수치를 실제 학교 규칙으로 사용하면 안 됩니다.

## 프로그램에서 사용

1. 시험지 수합에서 실제 학교 양식을 선택합니다.
2. 학교 양식 인식 결과에서 **AI JSON 불러오기…**를 선택합니다.
3. 후보 표와 **JSON 전체 근거**를 확인합니다. 확인 불가·충돌·조건부 항목을 실제 양식과 대조합니다.
4. 맞는 후보를 이번 작업에 사용하려면 **JSON의 비교 가능한 후보를 이번 작업의 기준으로 사용**을 선택합니다. 충돌을 바로잡을 때는 추가 지시에 역할과 값을 쓰고 추가 지시 우선 옵션을 선택합니다.
5. 확인 결과를 저장하고 기존 수합 절차를 진행합니다. 수합본 저장 후 선택한 비교 기준으로 다시 대조하며, 가져온 JSON과 채택 여부는 `.format-review.json`에 남습니다.

AI 분석용 서식 근거 JSON, AI가 작성한 규칙 JSON, 앱의 검토 결과 JSON은 서로 다른 파일입니다. **AI JSON 불러오기**에는 `schema: hwp-exam-template-analysis`인 규칙 JSON을 선택하세요.

## 현재 가능한 범위

글꼴·크기·줄간격 등 지원 속성은 원본에서 읽은 값 및 수합 후 문서와 비교할 수 있습니다. 추정·조건부 규칙은 자동 비교하지 않습니다. 페이지 설정, 개별 위치 좌표·배치 기준·여백·테두리 등은 JSON과 전체 근거에 보관하지만 현재 자동 비교에 연결하지 않았습니다. 화면에서의 겹침·잘림 검증이나 문서 전체 서식 자동 적용도 아직 포함하지 않습니다.

AI가 HWP 속성을 보지 못하면 정확한 글꼴·pt·줄간격·개체 좌표를 확정하기 어렵습니다. PDF/이미지와 프로그램의 서식 근거를 함께 제공하면 시각 정보와 읽어낸 속성을 대조할 수 있습니다. 이 프로그램은 AI에 자료를 자동 전송하지 않습니다.
