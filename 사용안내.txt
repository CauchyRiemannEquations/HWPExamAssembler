시험지 편집기 공용판 사용 안내

한컴오피스 한글이 설치된 Windows PC에서 아래 주소의 HWPExamAssembler-Public.exe를 내려받아 더블클릭하세요. 별도 설치나 압축 해제는 필요 없습니다. 한글이 파일 접근을 물으면 선택한 문서를 확인하고 허용하세요.
https://github.com/CauchyRiemannEquations/HWPExamAssembler/releases/latest/download/HWPExamAssembler-Public.exe

처음 양식을 등록할 때

1. 홈에서 ‘내 학교 양식 선택…’을 눌러 본인이 사용할 학교 시험지 HWP 또는 HWPX를 엽니다.
2. 왼쪽 목록에서 시험지 머리말, 기존 문항, 새 문항 시작 위치, 마지막 안내를 차례로 눌러 오른쪽 한글 작업 사본에서 위치를 확인합니다. 틀린 항목만 선택해 한글에서 범위나 커서 위치를 다시 지정하세요.
3. ‘등록하고 사용’을 누릅니다. 다음에 앱을 열면 최근 학교 양식에서 ‘수합 시작’으로 이어집니다.

출제 파일을 수합하고 편집할 때

4. 새 수합본 이름과 위치를 정하고 출제 파일들을 추가하세요. 필요한 경우 ‘서식 기준 보기…’에서 학교 양식의 글꼴·줄간격 등 지원 항목을 검토할 수 있습니다.
5. 수합본을 저장하면 편집 화면이 열립니다. ‘한글에서 확인’을 눌러 실제 시험지를 옆에 열어 두세요. 앱에서 문항을 끌거나 순서 번호를 선택하면 새 순서가 한글에 자동으로 저장되고, 방금 옮긴 문항으로 이동합니다.
6. 앱에서 해당 문항의 ‘하·중·상’을 누르거나 다음 문항을 옮기세요. 삭제할 문항이 있으면 목록에서 제거한 뒤 ‘순서·삭제 반영’을 눌러 확정하세요. 실제 인쇄 전에는 한글에서 쪽 나눔과 수식·그림 배치를 확인하세요.

이미 만든 수합본은 홈 화면에 끌어 놓거나 ‘편집본 열기…’로 여세요. 목록이 뜨면 곧바로 문항을 옮기고 난이도를 지정할 수 있습니다. 한글을 닫아 둔 상태에서는 ‘순서만 반영’을 눌러 새 순서를 파일에 저장하세요.

양식 구조를 AI로 확인하고 싶을 때

양식 등록 화면에서 ‘AI로 영역 제안…’을 누른 뒤 ‘보낼 내용 보기’를 열어 보세요. 문단 번호, 문항 번호 후보, 표와 수식 같은 구조 단서가 표시됩니다. 파일·문항 본문·정답을 첨부할 필요가 없습니다.

· ChatGPT를 선택하고 ‘ChatGPT로 계속’을 누릅니다. 브라우저에서 참여 가능한 Plus·Pro 계정으로 로그인해 사용을 승인하세요. 앱에 돌아와 첫 분석을 확인하면 제안이 표시됩니다. 사용량은 승인한 ChatGPT 요금제에 반영됩니다.
· Gemini를 선택하면 기관에서 설정한 Google Cloud 프로젝트를 이용합니다. ‘Google로 계속’에서 허용된 Google 계정으로 승인하세요. 기관에서 JSON을 따로 받았다면 ‘기관용 Google 설정 파일 선택…’을 누릅니다. 교사가 개인 API 키를 발급할 필요는 없습니다.
· 평소 쓰는 웹 대화를 이용하려면 ‘웹에서 복사·붙여넣기로 분석’을 선택합니다. 요청을 브라우저에 붙여넣어 보내고, 답변을 복사한 뒤 앱에서 ‘답변 붙여넣어 확인’을 누르세요.

변경 전후를 보고 ‘제안 적용’을 누른 뒤 한글에서 확인하세요. 제안이 마음에 들지 않으면 창을 닫고 직접 위치를 짚을 수 있습니다. 인터넷 연결과 AI 계정 없이도 양식 등록, 수합, 편집을 할 수 있습니다.

변경 기록과 서식 파일

문항 난이도·수합 기록, 백업, 서식 검토와 저장 후 대조 결과는 PC에 남습니다. 수합 시 저장한 .format-review.json에는 가져온 서식 규칙과 근거가 포함될 수 있습니다. .format-check.json은 당시 저장본과의 비교 결과입니다. 한글에서 이후에 변경한 내용은 문서에서 다시 확인하세요.

계정 및 전송 정보는 PRIVACY.md, v0.2.0-alpha의 서식 JSON 사용 방법은 docs/ai-template-profile.md를 참고하세요.
