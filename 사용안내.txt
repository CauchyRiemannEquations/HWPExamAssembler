HWP 시험문제 수합·편집기 — 공유용 알파판 상세 사용안내

============================================================
1. 이 프로그램은 무엇을 하나요?
============================================================

여러 교사가 한컴오피스 한글(HWP/HWPX)로 작성한 시험 문항을 모아서
학교 시험지 양식의 작업 사본에 배치하고, 나중에 문항 순서와 번호를
다시 정리하는 Windows용 보조 도구입니다.

이 프로그램은 문제를 새로 만들거나 내용을 재작성하지 않습니다.
문항을 텍스트, OCR, 화면 캡처 또는 LaTeX로 변환하지 않고 한글의
네이티브 복사·붙여넣기를 우선 사용합니다. 따라서 수식, 그림, 표,
도형, 글상자 등은 가능한 한 원래 한글 개체 상태로 옮깁니다.

현재 버전은 알파판입니다. 실제 시험에 사용하기 전에는 반드시
완성된 HWP를 한글에서 직접 열어 문항 누락, 번호, 배점, 수식, 그림,
표, 페이지 나눔과 마지막 안내 블록을 확인해 주세요.


============================================================
2. 준비물과 필수 환경
============================================================

[필수 환경]
- Windows 11 권장
- 한컴오피스 한글 2022 계열 설치
- HWP/HWPX 파일을 열고 저장할 수 있는 권한
- Python은 설치하지 않아도 됩니다.

[작업 전에 준비할 파일]
1) 실제로 사용할 시험지 양식 HWP 또는 HWPX
2) 교사별 출제 원본 HWP 또는 HWPX
3) 결과 시험지를 저장할 쓰기 가능한 폴더

양식은 예시 문항이 없는 빈 양식을 권장합니다. 예시 문항이 포함된
양식도 사용할 수 있지만, 작업 사본을 한글에서 확인하여 예시만 직접
선택하고 삭제해야 합니다.

암호가 걸렸거나 배포용 문서로 보호된 파일, 읽기 전용 파일, 손상된
파일은 자동화가 실패할 수 있습니다. 가능하면 한글에서 정상적으로
편집·저장되는 사본을 준비하세요.


============================================================
3. 프로그램 받기와 실행
============================================================

[권장: Portable ZIP]
1) HWPExamAssembler_..._Portable.zip을 내려받습니다.
2) ZIP을 새 폴더에 완전히 압축 해제합니다.
3) 압축을 푼 폴더 안의 HWPExamAssembler_..._Portable.exe를 실행합니다.
4) 같은 폴더의 _internal 폴더는 실행에 필요합니다. 이름을 바꾸거나
   삭제하지 마세요.

Portable 폴더 안의 EXE 하나만 바탕화면 등에 따로 복사하면 실행되지
않습니다. 바로가기를 만들거나 폴더 전체를 함께 옮겨야 합니다.

[대안: 단일 EXE]
HWPExamAssembler_....exe 하나만 전달하여 실행할 수도 있습니다.
다만 실행할 때 내부 파일을 임시 폴더에 풀기 때문에 Portable판보다
처음 열리는 시간이 길 수 있고, 백신이나 SmartScreen의 검사가 더
오래 걸릴 수 있습니다.

[Windows SmartScreen이 나타날 때]
파일 출처를 확인한 뒤 ‘추가 정보’ → ‘실행’을 선택합니다. 기관 보안
정책이 실행을 차단한다면 임의로 보안 설정을 낮추지 말고 관리자에게
문의하세요.

[한글 파일 접근 승인]
첫 HWP 작업 때 한글이 파일 접근을 허용할지 묻는 창을 표시할 수
있습니다. 사용자가 직접 ‘모두 허용’을 눌러야 합니다. 프로그램은
보안 승인 버튼을 자동으로 누르거나 한글 보안 수준을 낮추지 않습니다.


============================================================
4. 가장 먼저 알아둘 작업 원칙
============================================================

- 양식 원본과 교사 원본은 직접 수정하지 않습니다.
- 선택한 양식을 새 수합본 경로로 복사한 작업 사본에서만 처리합니다.
- 양식 원본과 새 수합본에 같은 경로를 지정할 수 없습니다.
- 한글에서 작업 중인 파일에는 앱이 동시에 자동 편집을 실행하지
  않습니다. 안내에 따라 저장하고 해당 한글 문서 탭을 닫아야 합니다.
- 앱의 Q001, Q002 같은 표시는 실제 문제 번호와 다른 내부 식별자입니다.
  문항을 이동해도 QID는 유지되고 화면에 보이는 문제 번호만 다시
  매겨집니다.
- 자동 인식이 확실하지 않은 문항은 억지로 만들지 않고 해당 QID 자리를
  비워 둔 채 다음 문항 수합을 계속합니다.


============================================================
5. 새 시험지 수합본 만들기 — 전체 순서
============================================================

------------------------------
5-1. 새 수합 창 열기
------------------------------

1) 앱을 실행합니다.
2) 메인 화면에서 ‘양식으로 새 시험지 만들기…’를 누릅니다.
3) 새 수합 과정은 안전 확인을 위해 항상 실제 한글 창을 표시합니다.
   메인 화면의 표시 모드 선택은 완성된 편집본을 다시 읽거나 순서를
   재배열할 때 적용됩니다.


------------------------------
5-2. 양식과 출력 경로 설정
------------------------------

‘여러 출제 파일 자동 수합’ 창에서 다음 항목을 지정합니다.

[양식 HWP/HWPX]
‘양식 선택…’을 눌러 실제 사용할 시험지 양식을 선택합니다.

[본문 준비 방식]
- 빈 양식 그대로 사용
  예시 문항이 없고 바로 문항을 넣어도 되는 양식일 때 선택합니다.
- 예시문항을 한글에서 직접 정리
  양식에 견본 문항이나 삭제할 안내 내용이 있을 때 선택합니다.

[마지막 고정 블록]
- 없음
  시험지 끝에 항상 붙여야 할 표·상자·안내문이 없을 때 선택합니다.
- 양식에서 직접 선택
  학교별로 정해진 마지막 안내문, 표 또는 상자가 양식에 있을 때
  선택합니다. 프로그램에 고정된 문구는 없으며, 사용자가 선택한
  한글 블록 자체를 보관했다가 마지막에 한 번만 복원합니다.

[문항 구성 유형]
- 선택 안 함
  확실하지 않을 때 가장 안전한 선택입니다. 양식과 원본의 흐름을
  가능한 한 그대로 유지합니다.
- 순차형
  문항이 순서대로 독립적으로 이어지는 구성입니다.
- 혼합 지문형
  한 지문에 서로 다른 문항 유형이 연결되는 구성입니다.
- 장문 공통 지문형
  긴 공통 지문과 여러 하위 문항이 한 묶음인 구성입니다.
- 그림·자료 공유형
  하나의 그림·표·자료를 여러 하위 문항이 함께 사용하는 구성입니다.
- 독립 자료형
  각 문항이 독립된 자료를 가지는 구성입니다.

유형 선택은 문항 묶음과 간격 판단을 돕는 힌트입니다. 잘 모르겠으면
‘선택 안 함’을 고르고 결과를 한글에서 직접 정리하는 편이 안전합니다.

[새 수합본]
‘새 편집본 경로…’를 눌러 결과 파일명과 저장 위치를 정합니다.
양식 원본과 다른 파일명을 사용해야 하며, 아직 존재하지 않는 새
파일명을 지정하세요.

위 설정은 작업 사본을 연 뒤에는 바꿀 수 없으므로 먼저 확인합니다.

설정을 마쳤으면 ‘양식 작업 사본 열기 (한글 창 표시)’를 누릅니다.
앱이 양식 원본을 복사하여 작업 사본을 만들고 실제 한글로 엽니다.


------------------------------
5-3. 마지막 고정 블록 먼저 보관(선택 기능)
------------------------------

처음 설정에서 ‘양식에서 직접 선택’을 고른 경우에만 수행합니다.

1) 한글 작업 사본에서 시험지 마지막에 다시 넣을 안내문·표·상자 전체를
   하나의 연속된 범위로 선택합니다.
2) 글상자나 도형만이 아니라 함께 움직여야 하는 앞뒤 문단과 표가 있다면
   빠지지 않았는지 확인합니다.
3) 앱에서 ‘선택한 마지막 고정 블록 보관’을 누릅니다.
4) 보관에 성공하면 해당 블록이 작업 사본에서 사라집니다. 이는 정상이며,
   문항 수합 완료 시 마지막 문항 뒤에 한 번만 복원됩니다.

현재는 연속된 마지막 고정 블록 1개를 지원합니다. 서로 떨어진 여러
영역은 한 번에 보관할 수 없습니다. 복원 후에는 실제 한글에서 위치,
페이지 나눔, 테두리와 글자 배치를 반드시 확인하세요.

마지막 고정 블록이 필요 없으면 처음부터 ‘없음’을 선택합니다. 앱이
임의의 안내 문구나 상자를 새로 만들지는 않습니다.

주의: ‘없음’을 선택해도 양식에 이미 들어 있는 상자를 자동으로
지우지는 않습니다. 양식 끝에 있는 블록을 마지막 문항 뒤로 옮겨야
한다면 반드시 ‘양식에서 직접 선택’으로 보관하세요.


------------------------------
5-4. 양식의 예시 문항 정리
------------------------------

마지막 고정 블록이 있다면 반드시 5-3의 보관을 먼저 끝낸 뒤 예시를
삭제하세요. 예시 후보 자동 선택은 첫 후보부터 본문 끝까지 이어질 수
있기 때문입니다.

앱은 작업 사본을 분석하고 예시 문항 후보 수, 번호 스타일과 문항 간
빈 문단 정보를 표시합니다. 이 분석은 참고 정보이며 자동 삭제 명령이
아닙니다. 예시의 번호 서식과 문항 간격은 삭제 전에 이미 분석됩니다.

[예시가 없는 빈 양식]
아무 내용도 지우지 말고 ‘양식 정리 완료 · 수합 시작’을 누릅니다.

[예시 문항이 있는 양식]
방법 A — 감지 후보를 먼저 확인
1) 앱에서 ‘감지된 예시 영역 선택’을 누릅니다.
2) 한글 화면에서 선택 범위의 시작과 끝을 자세히 확인합니다.
3) 머리말, 꼬리말, 시험 제목, 표지, 다단 설정 또는 남겨야 할 안내가
   포함되었다면 삭제하지 않습니다. Esc를 눌러 선택을 취소한 다음
   한글에서 정확한 범위만 다시 선택합니다.
4) 범위가 정확할 때만 앱의 ‘현재 선택 영역 삭제’를 누릅니다.

방법 B — 한글에서 직접 범위 선택
1) 한글에서 삭제할 예시 문항 전체를 마우스나 Shift 선택으로 잡습니다.
2) 범위를 다시 확인합니다.
3) 앱에서 ‘현재 선택 영역 삭제’를 누릅니다.

삭제는 양식 원본이 아닌 새 작업 사본에만 적용됩니다. 자동 인식이
후보를 찾지 못해도 한글에서 직접 정확히 선택하여 삭제할 수 있습니다.

주의: ‘감지된 예시 영역 선택’은 선택만 할 뿐 자동으로 삭제하지
않습니다. 선택되었다는 이유만으로 바로 삭제하지 마세요.


------------------------------
5-5. 양식 준비 완료
------------------------------

예시 문항과 마지막 고정 블록 정리가 끝났으면
‘양식 정리 완료 · 수합 시작’을 누릅니다.

이후에는 양식 정리 버튼 대신 출제 파일 추가 단계로 넘어갑니다.


------------------------------
5-6. 교사 원본 파일 추가
------------------------------

1) ‘출제자’ 칸에 교사명을 입력합니다. 필수 입력은 아니지만 나중에
   문항을 구분하기 쉬우므로 입력을 권장합니다.
2) ‘출제 파일 추가… (여러 개 가능)’를 누릅니다.
3) 같은 출제자의 파일은 여러 개를 한꺼번에 선택할 수 있습니다.
4) 출제자가 다른 파일을 추가하려면, 첫 수합이 끝난 뒤 출제자 이름을
   바꾸고 같은 버튼을 다시 눌러 해당 파일을 추가합니다.
5) 필요한 교사 원본을 모두 추가할 때까지 반복합니다.

프로그램은 파일 전체에서 문항 경계를 찾아 QID를 자동 부여하고,
문항 블록을 작업 사본에 차례로 복사합니다. 문항 안의 수식·그림·표 등
한글 개체 수를 복사 전후에 비교하여 불완전한 복사를 감지합니다.

각 파일마다 ‘문항 묶음 분석’ 창이 표시됩니다. 실제 원본과 묶음 범위를
비교한 뒤 맞으면 ‘확인하고 수합 계속’, 이상하면 ‘이 파일 수합 취소’를
누릅니다. 공통 지문이나 공통 그림 묶음은 하나의 그룹 ID와 하위 QID로
등록되며 메인 화면에서 묶음 단위로 이동·삭제됩니다.


------------------------------
5-7. 자동 복사되지 않은 문항 처리
------------------------------

일부 문항에서 개체 수가 맞지 않거나 안전한 범위를 확정하지 못하면
‘직접 입력 필요’ 안내가 표시됩니다. 이 경우 앱은 작업 전체를 멈추지
않고 해당 QID의 빈 자리만 만든 뒤 다음 문항을 계속 수합합니다.

처리 방법:
1) 안내에 표시된 QID와 원본 파일명을 메모합니다.
2) 나머지 파일 수합을 끝까지 진행합니다.
3) 1차 수합본을 만든 뒤 한글에서 결과 파일을 엽니다.
4) 해당 빈 번호 바로 뒤에 커서를 놓습니다.
5) 원본 HWP에서 원래 문제 번호를 제외한 문항 내용을 네이티브 복사하여
   직접 붙여넣습니다. 원본 번호까지 넣으면 번호가 중복될 수 있습니다.
6) 수식, 그림, 표, 선택지와 문항 끝이 모두 들어갔는지 확인합니다.

빈 QID 자리 자체를 통째로 삭제하지 마세요. 내부 식별자가 유지되어야
나중에 앱에서 문항을 다시 찾고 순서를 바꿀 수 있습니다.


------------------------------
5-8. 1차 수합본 완성
------------------------------

필요한 출제 파일을 모두 추가한 뒤 ‘1차 수합본 만들기’를 누릅니다.
앱은 번호를 정리하고, 선택해 둔 마지막 고정 블록이 있으면 마지막에
한 번 복원하며, 저장 후 문항과 개체 상태를 다시 확인합니다.

완료되면 수합본이 메인 화면에 표시됩니다. 실제 한글에서도 반드시
열어 다음을 확인하세요.

- 전체 문항 수와 번호
- ‘직접 입력 필요’로 남은 빈 자리
- 수식 누락 또는 수식 개체 변형 여부
- 그림·표·도형·글상자의 크기와 위치
- 선택지 줄바꿈과 문단 간격
- 객관식/서답형 구분 문구
- 공통 지문과 하위 문항 범위
- 페이지 및 단 나눔
- 마지막 고정 블록의 위치와 내용


============================================================
6. 한글에서 직접 수정한 뒤 앱으로 다시 읽기
============================================================

1) 메인 화면에서 수합본을 선택한 상태로 ‘한글에서 직접 수정’을
   누릅니다.
2) 실제 한글에서 문장, 수식, 그림 크기, 표, 줄바꿈과 간격을 수정합니다.
3) 한글에서 반드시 저장합니다.
4) 해당 HWP/HWPX 문서 탭을 닫습니다. 한글 프로그램 전체를 종료할
   필요는 없지만 작업 파일은 닫혀 있어야 합니다.
5) 앱으로 돌아와 ‘편집 완료 · 다시 읽기’를 누릅니다.
6) 앱이 현재 저장된 HWP의 QID와 최신 문항 내용을 다시 읽습니다.

중요: 한글에서 저장하지 않은 내용은 앱이 읽을 수 없습니다. 파일이
한글에 열린 상태에서는 충돌 방지를 위해 순서 저장을 진행하지 않습니다.

문항의 시작과 끝을 통째로 잘라내거나 내부 식별 필드를 지우면 QID를
찾지 못할 수 있습니다. 문항 전체 이동은 앱의 순서 기능을 사용하고,
한글에서는 문항 내부 내용을 수정하는 방식을 권장합니다.


============================================================
7. 문항 순서 변경과 삭제
============================================================

[순서 변경]
- 문항 목록을 드래그앤드롭합니다.
- 한 문항을 선택하고 ‘위로’ 또는 ‘아래로’를 누릅니다.
- 두 문항을 선택하고 ‘선택한 두 문항 교환’을 누릅니다.
- ‘처음 순서로’를 누르면 아직 저장하지 않은 목록 변경을 되돌립니다.

[문항 삭제]
1) 삭제할 문항을 선택합니다.
2) ‘선택 문항 삭제’를 누릅니다.
3) 이 단계에서는 목록에 삭제 예정으로만 반영됩니다.
4) 실제 HWP에 반영하려면 ‘현재 편집본에 저장’을 눌러야 합니다.

[현재 파일에 반영]
1) 한글에서 해당 문서를 저장하고 닫습니다.
2) 앱에서 변경할 순서와 삭제 예정 문항을 마지막으로 확인합니다.
3) ‘현재 편집본에 저장’을 누릅니다.
4) 앱이 저장 전 파일을 backup 폴더에 복사합니다.
5) 현재 편집본 자체에 순서 변경·삭제와 번호 재부여를 적용합니다.
6) 저장·재개방 검증 후 결과 파일을 한글로 다시 엽니다.

문항 번호가 바뀌어도 QID는 바뀌지 않습니다. 번호 스타일은 양식에서
읽은 한글 문단 번호 또는 글자 모양을 우선 사용합니다. 양식에 번호
예시가 전혀 없다면 중립 기본 번호가 사용될 수 있으므로 최종 번호
글꼴과 크기를 한글에서 확인하세요.


============================================================
8. 기존 편집본 이어서 작업하기
============================================================

1) 메인 화면에서 ‘기존 편집본 열기’를 누릅니다.
2) 이 프로그램으로 QID를 등록한 HWP/HWPX를 선택합니다.
3) 앱이 현재 저장된 문항 목록과 순서를 읽습니다.
4) 필요하면 한글 직접 수정, 다시 읽기, 순서 변경 또는 삭제를 진행합니다.

QID가 없는 일반 HWP를 선택하면 원본을 수정하지 않고 원본 옆에
‘파일명_문항등록본.hwp’를 새로 만들어 QID를 자동 등록합니다. 같은
이름이 이미 있으면 ‘_문항등록본_2.hwp’처럼 새 이름을 사용합니다.
여러 교사 파일을 한 양식에 수합하는 작업은 반드시
‘양식으로 새 시험지 만들기…’ 흐름을 사용하세요.


============================================================
9. 화면 표시 모드와 백그라운드 모드
============================================================

[화면 표시 모드 — 권장]
- 실제 한글 창에서 열기, 선택, 복사, 붙여넣기와 이동 과정을 볼 수
  있습니다.
- 처음 사용하는 양식이나 복잡한 수식·그림이 있는 문서에 적합합니다.
- 작업 중 한글을 마우스나 키보드로 동시에 조작하지 마세요.
- 새 시험지 최초 수합은 이 선택과 관계없이 항상 한글 창을 표시합니다.

[백그라운드 모드]
- 한글 창을 숨기고 작업합니다.
- 이미 충분히 검증한 반복 작업에서만 권장합니다.
- 문제가 생기면 화면 표시 모드로 다시 실행하여 어느 단계에서
  실패하는지 확인하세요.


============================================================
10. 오류 상황별 대처
============================================================

[프로그램이 열리지 않음]
- Portable판이라면 ZIP을 완전히 풀었는지 확인합니다.
- EXE와 _internal 폴더가 같은 폴더에 있는지 확인합니다.
- Windows SmartScreen 또는 기관 백신의 차단 기록을 확인합니다.
- 한컴오피스 한글이 설치되어 있는지 확인합니다.
- 단일 EXE가 오래 멈춘 것처럼 보이면 Portable판을 사용해 봅니다.

[한글 접근 허용 창이 반복됨]
- 한글이 표시한 창에서 사용자가 직접 ‘모두 허용’을 선택합니다.
- 기관 정책으로 허용이 저장되지 않으면 관리자에게 문의해야 합니다.
- 프로그램이 승인 창을 대신 클릭하도록 만들지는 않았습니다.

[양식 예시 문항을 감지하지 못함]
- 자동 삭제하지 않는 것이 정상적인 안전 동작입니다.
- 한글 작업 사본에서 삭제할 범위를 직접 선택하고
  ‘현재 선택 영역 삭제’를 누릅니다.

[문항을 찾지 못하거나 번호가 잘못 나뉨]
- 공통 지문 번호, ‘서답형/서술형’ 표지, 표·글상자 안의 번호 등은
  문서에 따라 인식이 어려울 수 있습니다.
- 구조 확인 창과 1차 수합본을 비교합니다.
- 잘못 나뉜 문항은 원본에서 네이티브 복사하여 직접 보완합니다.

[네이티브 개체 복사가 불완전하다고 표시됨]
- 원본과 붙여넣은 결과의 수식·그림·표 개수가 다르다는 뜻입니다.
- 앱은 그 문항을 지우고 빈 QID 자리로 남긴 뒤 다음 문항을 계속합니다.
- 1차 수합본에서 해당 자리만 원본 HWP로부터 직접 복사·붙여넣기합니다.
- 경고를 무시하고 시험지를 배포하지 마세요.

[파일이 열려 있어 저장할 수 없음]
- 한글에서 문서를 저장합니다.
- 해당 문서 탭을 닫습니다.
- 앱에서 ‘편집 완료 · 다시 읽기’를 누른 뒤 다시 저장합니다.

[마지막 고정 블록 보관 실패]
- 한글에서 선택이 실제로 유지되어 있는지 확인합니다.
- 한 개의 연속 영역으로 다시 선택합니다.
- 글상자·표의 일부만 선택하지 않았는지 확인합니다.
- 계속 실패하면 ‘없음’으로 새 수합을 진행하고 마지막에 한글에서
  해당 블록을 직접 복사하는 것이 안전합니다.

[저장 결과가 예상과 다름]
- 결과 파일과 같은 위치의 backup 폴더를 확인합니다.
- 가장 최근 백업본을 한글에서 열어 내용을 확인합니다.
- 원본 양식과 교사 원본은 프로그램이 수정하지 않습니다.

[로그 위치]
시작 또는 실행 오류 확인용 로그는 다음 폴더에 저장됩니다.
%LOCALAPPDATA%\HWPExamAssembler\logs

11. 최종 검수 체크리스트
============================================================

□ 양식 원본이 아닌 새 수합본에서 작업했는가?
□ 예정된 모든 교사 파일과 모든 문항이 들어갔는가?
□ ‘직접 입력 필요’ 문항을 원본에서 보완했는가?
□ 문제 번호가 1번부터 끝까지 올바른가?
□ 객관식/서답형 구분과 공통 문항 범위가 올바른가?
□ 모든 한글 수식이 수식 개체로 남아 있고 내용이 정확한가?
□ 그림·표·도형·글상자가 잘리거나 이동하지 않았는가?
□ 배점, 선택지, 줄바꿈과 문항 간격이 올바른가?
□ 페이지·단 나눔과 여백이 학교 양식에 맞는가?
□ 마지막 고정 블록이 필요한 경우 한 번만 들어갔는가?
□ 마지막 페이지 이후 불필요한 빈 문단이나 빈 페이지가 없는가?
□ 최종 파일을 한글에서 저장하고 다시 열어 확인했는가?

12. 공유할 때 주의할 점
============================================================

- 가장 권장하는 배포물은 Portable ZIP입니다.
- 받은 사람은 반드시 압축을 완전히 풀어야 합니다.
- Portable EXE만 따로 보내지 마세요.
- 시험지 양식과 교사 원본은 프로그램에 포함되어 있지 않습니다.
- 실제 HWP/HWPX에는 개인정보와 시험 내용이 들어갈 수 있으므로
  메신저, 클라우드와 GitHub에 올릴 때 별도로 주의하세요.
- 새 버전을 배포할 때는 구형 EXE와 섞이지 않도록 새 폴더에 둡니다.

[편집 작업을 다른 PC에서 계속할 때]
최종 HWP를 열어 보기만 한다면 HWP/HWPX 하나만 전달해도 됩니다.
다른 PC의 앱에서 계속 재배열하려면 편집본과 같은 이름으로 생성된
`.import.json`, `.format.json`, `.qid.json`, `.audit.json` 파일 및
`backup` 폴더도 함께 보관하는 것이 안전합니다.


============================================================
13. 현재 버전의 한계
============================================================

- 학교마다 HWP 양식 구조가 매우 달라 예시 영역, 실제 삽입 위치와
  마지막 고정 블록을 사용자가 확인해야 합니다.
- 표·글상자·머리말 안의 번호 또는 비표준 문항 번호는 자동 인식하지
  못할 수 있습니다.
- 연속되지 않은 여러 마지막 고정 블록은 지원하지 않습니다.
- 양식에 번호 예시가 없으면 번호 글꼴을 완전히 추정할 수 없습니다.
- 한글 버전과 PC 보안 정책에 따라 Automation 동작이 다를 수 있습니다.
- 자동 수합 후의 세밀한 간격, 페이지 배치와 개체 위치 조정은 실제
  한글에서 마무리해야 합니다.

이 프로그램의 목적은 한글을 대신하는 것이 아니라, 반복적인 문항 수합과
재배열을 안전하게 줄이고 실제 한글 편집으로 자연스럽게 이어 주는 것입니다.
