# HWPExamAssembler

여러 교사가 한컴오피스 한글(HWP/HWPX)로 작성한 시험 문제를 한 문서에 수합하고, 문항 순서를 다시 배치하는 Windows용 도구입니다.

이 프로그램은 문제를 텍스트나 이미지로 다시 만드는 프로그램이 아닙니다. 한글 Automation을 이용해 수식·그림·표·글상자 등이 포함된 문항 범위를 가능한 한 **한글 네이티브 개체 상태로 복사·붙여넣기**합니다. 세밀한 수정은 익숙한 한글 프로그램에서 그대로 할 수 있습니다.

> 현재 버전은 `v0.1.0-alpha`입니다. 실제 시험지에 사용하기 전에 반드시 생성된 편집본의 수식, 그림, 표, 문항 번호와 페이지 구성을 한글에서 직접 검토해 주세요.

## 무엇을 다운로드하나요?

1. 오른쪽의 **Releases** 또는 [다운로드 페이지](https://github.com/CauchyRiemannEquations/HWPExamAssembler/releases)를 엽니다.
2. Assets에서 `HWPExamAssembler-v0.1.0-alpha-windows-portable.zip`을 받습니다.
3. GitHub가 자동으로 제공하는 `Source code (zip)`은 실행 프로그램이 아니므로 받지 않아도 됩니다.
4. ZIP 파일을 **완전히 압축 해제**한 뒤, 폴더 안의 `HWPExamAssembler.exe`를 실행합니다.

`HWPExamAssembler.exe`와 `_internal` 폴더는 항상 같은 위치에 두어야 합니다. Python을 별도로 설치할 필요는 없습니다.

다운로드 파일이 손상되지 않았는지 확인하려면 릴리스의 `SHA256SUMS.txt`와 파일 해시를 비교할 수 있습니다.

## 실행 환경

- Windows 11 권장
- 한컴오피스 한글 설치 필요
- HWP Automation을 사용할 수 있는 한글 버전 필요
- 일부 PC에서는 최초 실행 시 Windows SmartScreen 또는 한글의 파일 접근 허용 안내가 표시될 수 있음

## 빠른 사용 순서

1. **시험지 양식 선택**에서 학교가 제공한 빈 HWP/HWPX 양식을 고릅니다.
2. **출제 파일 추가**에서 교사별 문제 파일을 하나씩 추가합니다.
3. 프로그램이 문항 번호 후보를 읽고 QID를 부여합니다. 읽지 못한 문항은 건너뛰고 목록에 안내합니다.
4. **1차 편집본 생성**으로 양식 복사본에 문항을 수합합니다. 원본 파일은 덮어쓰지 않습니다.
5. 생성된 편집본을 한글에서 열어 문장, 수식, 그림 크기, 간격 등을 직접 수정하고 저장합니다.
6. 앱의 **현재 편집본 다시 읽기**로 수정된 문서를 기준으로 문항 목록을 갱신합니다.
7. 드래그앤드롭 또는 위/아래 이동으로 순서를 바꾸고 **현재 편집본에 저장**을 누릅니다.
8. 자동 백업이 만들어졌는지 확인하고 최종 시험지를 한글에서 검수합니다.

자세한 단계와 문제 해결 방법은 저장소의 [사용안내.txt](./사용안내.txt)를 참고하세요.

## 개인정보와 문서 유출에 관하여

HWPExamAssembler 자체는 다음 기능을 사용하지 않습니다.

- 생성형 AI 또는 외부 AI 서비스
- OpenAI 등 외부 API 및 API 키
- 문서의 클라우드 업로드
- 원격 분석·텔레메트리
- 자동 업데이트를 위한 네트워크 통신

시험지 내용은 PC에 설치된 한글 Automation을 통해 로컬에서 처리되며, 결과 파일·백업·로그도 사용자의 PC에 저장됩니다. 따라서 **이 앱이 시험 문제를 AI에 보내거나 자체 서버로 전송하지 않습니다.**

다만 사용자가 결과 파일을 이메일, 메신저, 클라우드 등에 직접 올리는 행위와 Windows·한컴오피스 자체 기능 또는 정책은 이 앱의 범위 밖입니다. 민감한 시험지는 학교 보안 지침에 따라 관리해 주세요. 더 정확한 설명은 [PRIVACY.md](./PRIVACY.md)에 있습니다.

## 문서 보존 원칙

- 수식을 LaTeX로 변환하지 않습니다.
- 이미지 캡처나 OCR로 문항을 재생성하지 않습니다.
- 학교 양식을 비슷하게 새로 디자인하지 않고 사용자가 지정한 양식을 기반으로 작업합니다.
- 1차 편집 이후에는 현재 편집된 HWP 파일을 최신 원본으로 취급합니다.
- 원본 문서는 덮어쓰지 않으며, 순서 변경 전 자동 백업을 만듭니다.

## 현재 제한 사항

- 학교마다 문항 번호, 공통 지문, 서답형 구분과 양식 구조가 달라 자동 인식이 완벽하지 않을 수 있습니다.
- 암호 또는 배포 제한이 설정된 문서는 한글에서 먼저 제한을 해제해야 할 수 있습니다.
- 한글 Automation이 네이티브 개체 복사를 비정상적으로 보고하는 문항은 해당 번호 자리를 비워 둔 채 다음 문항을 계속 처리하며, 사용자가 그 문항만 직접 붙여넣도록 안내합니다.
- 수합 후 수식·그림·표·공통 지문 범위와 문항 번호는 반드시 사람이 최종 확인해야 합니다.

## 배포 형태

이 저장소는 사용자를 위한 **배포 전용 저장소**입니다. 실행 파일은 Git 이력에 넣지 않고 GitHub Releases의 ZIP 파일로만 제공합니다. 개발 소스와 시험용 문서는 포함하지 않습니다.
